# OneServe ROADMAP（已知限制与计划）

本文件如实记录当前版本的已知限制与计划方向。**不承诺时间表**：排期由维护者按使用者反馈动态决定，欢迎在 issue 中反馈优先级。

## 已知限制 → 计划

### 1. full 档演示 consumer 开箱自动注册

- **现状（限制）**：`--profile full` 演示栈里的 consumer 未开箱自动注册，需经网关 Admin API 手动注册后才能跑通完整链路。
- **计划**：为 full 档演示 consumer 提供开箱自动注册（启动引导内完成），做到 `docker compose --profile full up` 后零手工步骤即可端到端演示。

### 2. 资产标签宽表查询返回字段集为空

- **现状（限制）**：资产标签宽表（`v1-svc-usr-asset-tag`）查询的返回字段集可能为空——列名蓝本与现役字段尚未完全对齐。
- **计划**：对齐列名蓝本与现役字段集，恢复完整返回。`v1-svc-usr-basic-info` 主路径不受影响，可正常使用。

### 3. `/v1/portal/grants` 遗留端点清理

- **现状（限制）**：`/v1/portal/grants` 下 `field`、`oa` 两个端点是旧 UI 的遗留，现役页面已不依赖。
- **计划**：随旧 UI 退役计划一并清理这两个端点，收敛 portal API 面。

### 4. README.en.md 英文版独立文件

- **现状（限制）**：README 采用中文为主＋英文折叠对照的形态，独立的 `README.en.md` 尚未建立（README 语言切换行已占位）。
- **计划**：落地独立的 `README.en.md` 英文版，与中文版保持同步更新。

### 5. 国内 Docker 镜像加速的 compose 原生支持

- **现状（限制）**：国内环境拉取镜像慢的问题目前靠 README 里的手工补丁说明解决，compose 未原生提供加速配置。
- **计划**：提供国内 Docker 镜像加速的 compose 原生支持方案（如 override 文件或镜像源变量化），减少手工改动。

## 维护者路线原则

文档与体验优先；功能按使用者反馈排期——issue 里被重复提出的，优先级自然上升。
